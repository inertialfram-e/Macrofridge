# Mobile Household Management UI Implementation Plan

## Overview
Implement the user interface for managing household membership. This includes creating a household, viewing current members, and ensuring the user is associated with a household before using inventory features.

## Scope Definition (CRITICAL)
### In Scope
- Create `apps/mobile/src/components/HouseholdManager.tsx`.
- Create `apps/mobile/src/components/HouseholdForm.tsx`.
- Implement logic to check for existing household membership on login.
- Implement SQL mutations to create a household and join the creator as 'admin'.
- Update `apps/mobile/App.js` to handle the household onboarding flow.
### Out of Scope (DO NOT TOUCH)
- Implementing invitation codes or deep linking (Phase 3).
- Advanced permission management (e.g., promoting/demoting members).
- Modifying the NestJS API.

## Current State Analysis
Mobile app has an inventory list but assumes a `household_id` exists (placeholder used in code). Users can log in but aren't forced into a household yet.

## Implementation Phases

### Phase 1: Membership Check & Onboarding
- **Goal**: Ensure every user belongs to a household.
- **Steps**:
  1. [x] Update `App.js` to query `household_members` for the current user.
  2. [x] If no membership exists, display the `HouseholdManager` (onboarding mode).
- **Verification**: Log in with a new user and verify you are prompted to create a household.

### Phase 2: Household Creation UI
- **Goal**: Allow users to create their first household.
- **Steps**:
  1. [x] Create `apps/mobile/src/components/HouseholdForm.tsx`.
  2. [x] Implement `handleCreate` using a transaction: `INSERT INTO households` then `INSERT INTO household_members`.
- **Verification**: Create a household and verify the app advances to the inventory screen.

### Phase 3: Member List & Settings
- **Goal**: Display who else is in the household.
- **Steps**:
  1. [x] Create `apps/mobile/src/components/HouseholdManager.tsx` (settings mode).
  2. [x] Implement a `db.watch()` query joining `household_members` and `users`.
- **Verification**: View the household settings and verify your own email appears in the list.
