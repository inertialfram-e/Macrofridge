# Mobile Inventory CRUD UI Implementation Plan

## Overview
Implement the user interface for managing household inventory. This includes a list view of all items and a form for adding, editing, and deleting items. The UI will interact with the local PowerSync SQLite database for persistence and synchronization.

## Scope Definition (CRITICAL)
### In Scope
- Create `apps/mobile/src/components/InventoryList.tsx`.
- Create `apps/mobile/src/components/InventoryItem.tsx`.
- Create `apps/mobile/src/components/InventoryForm.tsx`.
- Implement `db.watch()` logic to reactively update the list.
- Implement SQL mutations for Add, Update, and Delete.
- Update `apps/mobile/App.js` to include the inventory view.
### Out of Scope (DO NOT TOUCH)
- Implementing barcode scanning or OCR (Phase 3).
- Implementing household management UI (Ticket `b3a4c5d6`).
- Adding advanced navigation libraries (for now, will use simple conditional rendering).

## Current State Analysis
Mobile app has PowerSync initialized but no inventory-related UI. `App.js` shows a simple "Welcome" message for logged-in users.

## Implementation Phases

### Phase 1: List View Implementation
- **Goal**: Display all inventory items from the local database.
- **Steps**:
  1. [x] Create `apps/mobile/src/components/InventoryItem.tsx` for individual item rows.
  2. [x] Create `apps/mobile/src/components/InventoryList.tsx` using `db.watch()` to query `inventory_items`.
- **Verification**: Manually add a dummy record to SQLite and verify it appears in the list.

### Phase 2: CRUD Logic & Form
- **Goal**: Enable adding, editing, and deleting items.
- **Steps**:
  1. [x] Create `apps/mobile/src/components/InventoryForm.tsx` with fields for name, quantity, unit, and expiry.
  2. [x] Implement `handleSave` logic using `db.execute()` for `INSERT` and `UPDATE`.
  3. [x] Implement `handleDelete` logic using `db.execute()` for `DELETE`.
- **Verification**: Use the form to add an item, edit it, and then delete it. Verify the list updates automatically each time.

### Phase 3: Main UI Integration
- **Goal**: Integrate the inventory view into the main app flow.
- **Steps**:
  1. [x] Update `apps/mobile/App.js` to display the `InventoryList` when a user is logged in.
- **Verification**: `pnpm dev` in `apps/mobile` shows the functional inventory screen after login.
