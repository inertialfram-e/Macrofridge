# Scaffold Mobile and API Apps Implementation Plan

## Overview
Generate the initial application structures for the mobile (Expo) and API (NestJS) layers within the `apps/` directory of the monorepo.

## Scope Definition (CRITICAL)
### In Scope
- Create `apps/` directory.
- Scaffold `apps/mobile` using `create-expo-app`.
- Scaffold `apps/api` using `nestjs-cli`.
- Update root `package.json` to include scripts for building and linting these apps.
### Out of Scope (DO NOT TOUCH)
- Implementing specific features in either app.
- Database or PowerSync integration.
- Shared logic implementation.

## Current State Analysis
Root configuration exists, but the `apps/` directory and applications are missing.

## Implementation Phases

### Phase 1: App Scaffolding
- **Goal**: Generate the boilerplate for both applications.
- **Steps**:
  1. [x] Create `apps/` directory.
  2. [x] Run `npx create-expo-app@latest apps/mobile --template blank --yes`.
  3. [x] Run `npx @nestjs/cli new apps/api --package-manager pnpm --skip-git --yes`.
- **Verification**: Ensure directories `apps/mobile` and `apps/api` contain expected files (`package.json`, `src/` or `App.ts`).

### Phase 2: Monorepo Integration
- **Goal**: Ensure the new apps work with the root workspace.
- **Steps**:
  1. [x] Run `pnpm install` from root to link dependencies.
  2. [x] Update `apps/mobile/package.json` and `apps/api/package.json` to change their `name` to `@macrofridge/mobile` and `@macrofridge/api`.
- **Verification**: `pnpm -r exec ls` should show both apps.

### Phase 3: Turbo Configuration Verification
- **Goal**: Verify Turbo can orchestrate tasks.
- **Steps**:
  1. [x] Run `pnpm build` from root.
- **Verification**: Turbo should report tasks for both applications (even if they are default builds).
